rtext — Fonts & Text Rendering

src/rtext.c loads fonts (TTF, sprite fonts, etc.), builds a GPU glyph atlas (Font.texture), and renders strings as a sequence of textured quads — the same 2D batch path as textures.

Font Structure

A Font is not a GPU object by itself — it bundles metadata plus one atlas texture:

  • texture — Texture2D atlas containing all glyph bitmaps
  • recs[] — source rectangle in atlas per glyph index
  • glyphs[] — advance, offset, and codepoint mapping
  • baseSize — reference pixel height for scaling

At startup, rcore calls LoadFontDefault() which embeds a small bitmap font (DejaVu-derived) so DrawText works without loading external files.

TTF loading uses stb_truetype (in src/external/). You can restrict codepoints with LoadFontEx to keep atlas size small — important for CJK.

void DrawTextEx(Font font, const char *text, Vector2 position, ...)
{
    for each UTF-8 codepoint in text:
        if codepoint == '\n' → advance line
        else DrawTextCodepoint(font, codepoint, position + offset, ...);
}

void DrawTextCodepoint(Font font, int codepoint, Vector2 position, ...)
{
    int index = GetGlyphIndex(font, codepoint);
    Rectangle srcRec = font.recs[index];     // atlas region
    Rectangle dstRec = { position + offset, scaled size };
    DrawTexturePro(font.texture, srcRec, dstRec, {0,0}, 0, tint);
}
DrawText → DrawTextCodepoint

Each character is one DrawTexturePro call → four vertices in the rlgl batch. Long strings mean many quads but still batched by texture (single atlas = efficient).

UTF-8 Handling

GetCodepointNext walks the input byte string, decoding UTF-8 into Unicode codepoints. GetGlyphIndex maps a codepoint to an atlas index, falling back to '?' for missing glyphs.

Spacing uses glyphs[index].advanceX scaled by fontSize / baseSize. Line breaks respect textLineSpacing (set via SetTextLineSpacing).

Rotated Text 
void DrawTextPro(Font font, const char *text, Vector2 position,
                 Vector2 origin, float rotation, ...)
{
    rlPushMatrix();
        rlTranslatef(position.x, position.y, 0);
        rlRotatef(rotation, 0, 0, 1);
        rlTranslatef(-origin.x, -origin.y, 0);
        DrawTextEx(font, text, (Vector2){0, 0}, ...);
    rlPopMatrix();
}
DrawTextPro

Uses rlgl's matrix stack — vertices are transformed before entering the batch when transformRequired is set.

Text Measurement (CPU)

MeasureText, MeasureTextEx iterate codepoints and sum advance widths without touching the GPU. Useful for centering UI labels.

DrawTextCodepoints skips UTF-8 decoding when you already have an int array — handy for internationalization tables.

Connection to rshapes

The default font atlas provides the white pixel region that rshapes uses for solid fills. This design choice unifies batching: shapes and text share one texture bind when drawn interleaved (same atlas for default font + shapes, or default 1×1 texture otherwise).
