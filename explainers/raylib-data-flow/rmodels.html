rmodels — 3D Models, Meshes & Materials

src/rmodels.c loads 3D assets (glTF, OBJ, IQM, M3D, etc.), uploads mesh data to GPU buffers, and draws with per-material shaders — outside the 2D render batch.

glTF loading uses cgltf.h in src/external/. Each mesh uploads once; drawing reuses GPU buffers.

Drawing Pipeline

3D drawing requires BeginMode3D first (see rcore). Then:

void DrawModelEx(Model model, Vector3 position, Vector3 axis,
                 float angle, Vector3 scale, Color tint)
{
    // Build transform: scale → rotate → translate
    Matrix matTransform = MatrixMultiply(
        MatrixMultiply(MatrixScale(...), MatrixRotate(...)),
        MatrixTranslate(...));
    model.transform = MatrixMultiply(model.transform, matTransform);

    for each mesh i:
        Material mat = model.materials[model.meshMaterial[i]];
        apply tint to diffuse color
        upload bone matrices if skeletal animation
        DrawMesh(model.meshes[i], mat, model.transform);
}

DrawMesh — Shader & GPU Path

Unlike 2D shapes, DrawMesh bypasses the vertex batch. It binds the material's shader, uploads matrices and material uniforms, binds texture maps, and calls glDrawElements:

void DrawMesh(Mesh mesh, Material material, Matrix transform)
{
    rlEnableShader(material.shader.id);

    // Upload diffuse/specular colors as uniforms
    rlSetUniform(SHADER_LOC_COLOR_DIFFUSE, ...);

    // Model / view / projection / normal matrices
    Matrix matModel = MatrixMultiply(transform, rlGetMatrixTransform());
    rlSetUniformMatrix(SHADER_LOC_MATRIX_MODEL, matModel);
    rlSetUniformMatrix(SHADER_LOC_MATRIX_VIEW, rlGetMatrixModelview());
    rlSetUniformMatrix(SHADER_LOC_MATRIX_PROJECTION, rlGetMatrixProjection());

    // Bind each material map to texture slot i
    for each map with texture.id > 0:
        rlActiveTextureSlot(i);
        rlEnableTexture(map.texture.id);

    // Draw indexed triangles from mesh VAO
    glBindVertexArray(mesh.vaoId);
    glDrawElements(GL_TRIANGLES, mesh.triangleCount*3, ...);
}
DrawMesh (GL 3.3 path)

Each mesh draw may flush the 2D batch first if a prior rlSetTexture left pending vertices — another reason rcore calls rlDrawRenderBatchActive at mode boundaries.

Procedural 3D Shapes

rmodels also generates meshes for primitives: GenMeshCube, GenMeshSphere, GenMeshPlane, heightmaps, etc. These build CPU vertex arrays then call UploadMesh — same draw path as loaded assets.

Wireframe overlays use rlEnableWireMode() around DrawModel.

Billboards

DrawBillboard* functions orient a textured quad toward the camera using the view matrix from BeginMode3D. They still use the 2D textured-quad path (DrawTexturePro style logic in 3D space) rather than DrawMesh.

Skeletal Animation

For animated models, UpdateModelAnimation computes bone transform matrices each frame into model.boneMatrices. DrawModelEx uploads them to SHADER_LOC_MATRIX_BONETRANSFORMS for GPU skinning in the vertex shader.

Animation data comes from glTF skins or IQM files at load time.
