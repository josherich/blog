Yeah, so this is the power behind this form of software called **agentic software**. So this is basically what **Cursor** is and many other products are, which is the core idea of an **agent**.

Today, the most popular architecture for agents is called a **React-style agent**. And so React-style agent is basically a **reasoning and an acting agent**. And so what it does is that the **LLM reasons and then it acts**. And the way it acts is you give it **tools**. So you say, hey, you can go search the web, for example. Or you can, in the Cursor case, you can go modify some code or you can go run some code, for example.

And so you can sort of watch, reason, and act, basically.
