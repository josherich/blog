GitHub token

Uploads are committed directly to josherich/blog on the gh-pages branch. The token is stored only in this browser.

Create the token

  1. Open GitHub → Personal access tokens → Fine-grained tokens.
  2. Repository access: Only select repositories → josherich/blog.
  3. Permissions: Contents → Read and write. Leave everything else off.
  4. Set an expiration, generate the token, copy it, and paste it above.

Because this is a static GitHub Pages site, no server ever sees the token. A token with write access to this repository could change the repository, so keep it private and let it expire.

About this page

Photos are stored in photos/media/ and the timeline index is photos/data.json. New uploads use the GitHub API, so they appear immediately even before GitHub Pages finishes rebuilding.
